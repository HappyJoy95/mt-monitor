# 美团订单监控设计

## 目标

建立一个本地美团商家订单采集项目。每次运行从已登录的本地浏览器会话拉取订单列表，保存完整原始响应，并生成便于查看的订单摘要。

## 范围

- 使用本地浏览器资料中的现有登录状态。
- 按需执行一次订单列表拉取。
- 原始响应原样保存到 `raw/`，文件名包含拉取时间。
- 生成最新订单摘要到 `data/latest-orders.json`。
- 登录态、Cookie 与其他认证数据不写入项目文件。

## 目录与职责

- `src/`：请求、保存、摘要转换与命令入口。
- `raw/`：完整接口响应，保留用于审计和二次解析。
- `data/`：从原始数据派生的最新订单摘要。
- `config/`：不含密钥的运行参数与示例配置。
- `README.md`：安装、运行和查看数据的说明。

## 数据流

浏览器会话 → 美团订单接口 → `raw/` 原始 JSON → 摘要转换 → `data/latest-orders.json`。

若请求失败，命令返回明确错误且不覆盖任何已有原始文件或摘要。

## 验收标准

执行一次拉取命令后，`raw/` 出现一份完整 JSON 响应，`data/latest-orders.json` 出现与该响应一致的订单摘要；项目中不包含认证数据。
